# PlanificaCL 🇨🇱

**PlanificaCL** es una plataforma educativa de planificación instruccional de nivel experto diseñada para el sistema escolar chileno. Utiliza Inteligencia Artificial avanzada para estructurar planificaciones de clase, unidades didácticas y programas anuales en perfecta coherencia con las Bases Curriculares nacionales, el Marco para la Buena Enseñanza y el Decreto 67 de evaluación formativa.

## 🚀 Despliegue Automático
Este proyecto se despliega automáticamente en **Firebase Hosting** mediante GitHub Actions.
*   **Sitio de Producción**: [https://planificacl.web.app](https://planificacl.web.app)
*   **Sitio Secundario (Pages)**: [https://paes777.github.io/PlanificaCL/](https://paes777.github.io/PlanificaCL/)

## 🛠️ Tecnologías
*   **Frontend**: HTML5, Vanilla CSS3 (Glassmorphism & dark mode UI), Vanilla Javascript.
*   **IA de generación**: API de Pollinations (modelos GPT-4/Mistral/Command R+).
*   **Despliegue**: GitHub Actions y Firebase Hosting.
